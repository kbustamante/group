# Apps del grupo (GitHub Pages)

Pantallas instalables de las empresas del grupo. Los datos viven en Google Sheets y la lógica en Google Apps Script; aquí solo está la pantalla.
El código fuente está en el repo privado `kbustamante/lacteos-fuente` y se publica aquí con `scripts/publicar.sh`.

- Inicio del grupo: https://kbustamante.github.io/group/
- Lácteos (la del día a día): https://kbustamante.github.io/group/lacteos/ (ícono azul)
- Lácteos PRUEBA: https://kbustamante.github.io/group/lacteos-prueba/ (ícono naranja "PRUEBA"), conectada a la copia de prueba.

Cada app está en su propia carpeta (sin carpetas anidadas) para que las dos instaladas no se mezclen.
La dirección vieja (kbustamante.github.io/lacteos/real/ y /prueba/) redirige aquí desde el repo `kbustamante/lacteos`.
